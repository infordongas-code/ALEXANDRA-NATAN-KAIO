# Portfólio de Filosofia — Professora Ana Lurdes

Site educativo responsivo feito com HTML, CSS e JavaScript puro, pronto para editar no Visual Studio Code.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta `portfolio_ana_lurdes` no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador. Se tiver a extensão **Live Server**, clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Arquivos
- `index.html` — conteúdo e estrutura da página.
- `css/style.css` — cores, tipografia, layout e responsividade.
- `js/script.js` — menu para celular, pesquisa de pensadores, perguntas aleatórias e pista de reflexão.

## Personalização
O conteúdo apresenta conceitos introdutórios de Filosofia. Para transformar o modelo em um portfólio pessoal da professora, edite a apresentação e adicione informações confirmadas, projetos realizados, materiais de aula e canais institucionais de contato.

O site não exige instalação de bibliotecas. A fonte tipográfica do Google Fonts é opcional; se não houver internet, serão usadas fontes alternativas locais.
